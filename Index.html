SECURITY GUIDE

Build safer habits.

01 / Unique passwords

Use a password manager and a different strong password for every account.

02 / Multi-factor authentication

Enable MFA or passkeys. Keep recovery codes somewhere safe.

03 / Verify links

Check the actual domain, not just the message or link display text.

04 / Update your devices

Install security updates and remove apps you no longer use.

05 / Back up your files

Keep backups and periodically test that you can restore them.

06 / Stop and verify

Verify urgent payment requests and never share one-time codes with strangers.
